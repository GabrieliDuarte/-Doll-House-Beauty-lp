# API - Doll House Beauty 💅

Backend desenvolvido para o sistema de agendamentos e gestão do salão Doll House Beauty.

## Como rodar o projeto
1. Instale as dependências: `npm install`
 npm i -D typescript tsx @types/pg @types/express @types/node
 npm i pg express dotenv
 npm install pg express dotenv
npm install --save-dev typescript tsx @types/pg @types/express @types/node

2. Inicie o servidor: `npm run dev`
